## COURSE SYLLABUS IN COMPUTER PROGRAMMING 1
**Academic Year:** 2023 to 2024
* **Course Code:** CCP 1101
* **Course Title:** COMPUTER PROGRAMMING 1 (PYTHON)
* **Credit Units:** Lecture 2 units, Laboratory / Studio 1 unit
* **Course Type:** PURE ONSITE [ ], PURE OFFSITE [ ], HYBRID [x] (Onsite + Offsite), Others [ ]
* **Pre-requisite(s):** Course Code, Course Title
### Course Description
Procedural programming, algorithm design, and language constructs to high level programming language.
### Course Outcomes
Upon completion of the course, the learner will be able to:
* Implement a given algorithm as a computer program in Python.
* Adapt and combine standard algorithms to solve a given problem (includes numerical as well as non-numerical algorithms).
* Adequately use standard programming constructs: repetition, selection, functions, composition, modules, aggregated data (such as arrays and lists).
* Explain what a given Python program does.
* Identify and repair coding errors in a program.

### 7th to 9th Week
* **Hours:** Lecture: 6 hours; Laboratory: 9 hours.
* **Content:**
* Loops (While statement, For statement, While/Else and For/Else).

* **Learning Outcomes:**
* Write a loop to repeat a sequence of actions a fixed number of times.
* Write a loop that counts down and a loop that counts up.
* Write an entry-controlled loop that halts when a condition becomes false.
* Construct appropriate conditions for condition-controlled loops and selection statements.
* Explain why functions are useful in structuring code in a program.
* Employ top-down design to assign tasks to functions.
* Define a function with required and optional parameters.
* **Teaching-Learning Activity:**
* Programming Activity, Multimedia Presentation, Lecture, Code Demonstration (Modality: A S O ☑ ☑ ☑ ☑ ✓).
